# Finura — Smart Finance 💰

A full-stack personal finance management application designed to help users manage their money with better visibility, planning, and financial insights.

## 🚀 Features

- 💰 Personal finance management
- 📊 Financial analytics
- 🎯 Smart budgeting and planning
- 💳 Credit management
- 🤖 AI-powered financial features
- 🔐 Secure authentication
- 🛡️ Secure data management
- 📈 Wealth and financial tracking

## 🛠️ Tech Stack

- Frontend: React / Vite
- Backend: Node.js
- API: REST API
- Database: MongoDB
- Authentication: JWT
- Styling: Modern responsive UI

## 🎯 Project Goal

Finura aims to provide users with a simple and secure platform to understand their finances, track spending, manage budgets, and make better financial decisions.
